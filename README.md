# Iris Classifier (Decision Tree)

## Overview

End to end example from AI Fundamentals Module -> builds a decision tree classifier on classic Iris dataset with scikit-learn

## Quick start

```bash
git clone https://github.com/Mors1A4/Iris-classifier.git
cd Iris-classifier
python -m venv venv
pip install -r requirements.txt
python src/tain.py

#optional
python src/train.py --test_size x.x --random_state x
```
